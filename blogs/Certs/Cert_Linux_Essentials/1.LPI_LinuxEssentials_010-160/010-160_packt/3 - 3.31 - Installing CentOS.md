## Installing CentOS
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Locate the files required to install CentOS.
2. Create installation media for CentOS.
3. Perform an installation of CentOS on a physical or virtual machine. 

### External Resources:

During this episode, you can reference the following external resources for supplementary tools and information:

* [CentOS System Requirements](https://wiki.centos.org/About/Product)
* [Download CentOS](https://www.centos.org/download/)
* [Make USB Install Media](https://wiki.centos.org/HowTos/InstallFromUSBkey)
