## Redirecting Command Output
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Redirect command output to another command using pipes.
2. Redirect command output to a file using redirects. 
3. Identify when to use pipes versus redirects.
