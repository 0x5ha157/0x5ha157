## Linux File Permissions
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. View and identify file permissions from the Linux command line.
2. Modify file permissions using the `chmod` command. 
3. Change file group and user ownership using the `chown` command.
