## Using the Root User Account
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Identify the root user accounts and differentiate it from unprivileged user accounts. 
2. Assume another user's identity using the `su` command. 
3. Execute commands as root using the `sudo` command.
