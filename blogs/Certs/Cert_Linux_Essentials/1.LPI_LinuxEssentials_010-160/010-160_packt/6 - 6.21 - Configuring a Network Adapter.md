## Configuring a Network Adapter
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Use ip and ifconfig to view network configurations. 
2. Use nmtui to configure a network adapter from the command line. 
3. Use nmcli to configure a network adapter from the command line.
