## Installing Software with rpm
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Determine when it is appropriate to use rpm to install software. 
2. Install software from the command line using rpm. 
3. List and remove previously installed software using rpm.
