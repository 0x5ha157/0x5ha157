## Managing User Accounts
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Create user accounts from the command line using useradd. 
2. Modify and delete user accounts using passwd, usermod and userdel. 
3. View and modify the default values for user accounts.
