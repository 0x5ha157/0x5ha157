## Installing Ubuntu
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Locate the files required to install Ubuntu Linux.
2. Create installation media for Ubuntu.
3. Perform an installation of Ubuntu Linux on a physical or virtual machine.

### External Resources:

During this episode, you can reference the following external resources for supplementary tools and information:

* [Ubuntu System Requirements](https://help.ubuntu.com/community/Installation/SystemRequirements)
* [Download Ubuntu](https://www.ubuntu.com/download/desktop)
* [Make USB Install Media](https://tutorials.ubuntu.com/tutorial/tutorial-create-a-usb-stick-on-windows)

**Performing System Updates**

```
sudo apt update  
sudo apt upgrade  
sudo apt dist-upgrade  
```
