## Verifying Network Connectivity
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Use ifconfig and ip to view the network configuration. 
2. Establish the scope of a failure using ping, traceroute and tracepath. 
3. Test name resolution using nslookup and dig.
