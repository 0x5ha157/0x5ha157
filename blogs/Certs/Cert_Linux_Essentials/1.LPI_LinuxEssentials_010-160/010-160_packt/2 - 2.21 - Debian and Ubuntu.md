## Debian and Ubuntu  
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Differentiate Debian Linux and Ubuntu Linux.
2. Locate the websites for Debian and Ubuntu.
3. Describe the Debian release cycle and how it applies to Ubuntu.
