## Managing User Groups
##### LPI Linux Essentials (010-160)

### Objectives

At the end of this episode, I will be able to:

1. Create user groups from the command line using `groupadd`. 
2. Modify and delete user groups using `groupmod` and `groupdel`. 
3. Add user accounts to a group using `gpasswd`
